# Jetour — Sitio Web Automotriz

Proyecto frontend desarrollado para un cliente del sector automotriz (concesionaria de vehículos Jetour). El proyecto fue completado técnicamente pero el cliente decidió no desplegarlo. Se incluye en el portafolio como demostración de integración de múltiples servicios en React.

---

## Sobre el proyecto

El cliente requería un sitio web para mostrar su catálogo de vehículos, con mapa de ubicación, reproductor de video, formulario de contacto y opciones para compartir en redes sociales. El proyecto se desarrolló en su totalidad pero no llegó a producción por decisión del cliente.

## Stack tecnológico

- **React 18** — librería principal de UI
- **React Router 6** — enrutamiento
- **Google Map React** — integración de mapa interactivo
- **React Player** — reproductor de video embebido
- **React Share** — botones para compartir en redes sociales
- **EmailJS** — formulario de contacto sin backend
- **Create React App** — scaffolding del proyecto

## Características

- Catálogo de vehículos con fichas de producto
- Mapa interactivo con la ubicación de la concesionaria
- Reproductor de video integrado
- Formulario de contacto funcional vía EmailJS
- Botones de compartir en redes sociales

## Decisiones técnicas y contexto

En un proyecto nuevo utilizaría **Vite** en lugar de Create React App, que fue deprecado desde 2022. CRA fue elegido en su momento por familiaridad, pero la migración a Vite sería el primer paso antes de cualquier despliegue.
